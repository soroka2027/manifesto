# Manifesto App — «Війна як наслідок аполітичності»

Angular-застосунок (standalone components) з адаптивною версткою.

## Структура головної сторінки

**Ліва сторона:**
- Перемикач мови (ua | eng)
- Логотип у кружечку + посилання «& Grok»
- Анімований текст «Привіт Світ!» (ефект набору)
- Меню: Маніфест / За лаштунками / Інфопростір / Візуалізація / Про автора

**Права сторона:**
- Текст-інтро до маніфесту (українською та англійською)

## Стиль
Базується на твоєму резюме-застосунку:
- Чистий білий фон
- Шрифти: Inter (текст) + Playfair Display (заголовки)
- Акцентний колір: `#00b7c2` (cyan)
- Посилання без підкреслення, змінюють колір при hover

## Як запустити

```bash
cd manifesto-app
npm install
ng serve
```

Відкрий http://localhost:4200

## Адаптивність
- Desktop / Laptop — двоколонковий layout
- Tablet / Mobile — вертикальний (sidebar зверху)

## Наступні кроки
Можна додати окремі сторінки для кожного пункту меню та повний текст маніфесту.
